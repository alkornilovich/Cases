# Прототип команды № 11, Кейс-школа Альфа-Будущего

Персонализация коммуникаций с корпоративными клиентами Альфа-Банка. Один клиент (P1) глазами бухгалтера, финансового директора и клиентского менеджера: AS IS и TO BE, «что если», панель «Под капотом».

Демо: https://alkornilovich.github.io/Cases/alfa-future-11/
Для QR: https://alkornilovich.github.io/Cases/alfa-future-11/#boss

| Файл | Что это |
|---|---|
| `engine.js` | Движок правил, перенос `engine()` и `journey_rule()` из `profiles.py` один в один |
| `app.js` | Экраны, сценарий, «что если», «Под капотом» |
| `index.src.html` | Разметка и стили |
| `build.py` | Сборка в один файл `docs/alfa-future-11/index.html` |
| `tests/check.mjs` | Сверка движка с `expected_output`: `node tests/check.mjs` → 10 из 10 |
| `ЛОГИКА_ПРОЕКТА.md` | Решения и расхождения ТЗ с эталонным движком |

Данные синтетические, это не сервис банка.

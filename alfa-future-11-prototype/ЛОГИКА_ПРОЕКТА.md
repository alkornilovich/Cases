## Решения и почему

**Движок перенесён один в один, а не написан заново.** Требование «результат совпадает с expected_output на 10 профилях» проверяемо только так. `engine.js` повторяет `resolve_role`, `engine`, `journey_rule` из `profiles.py` построчно. Тест `node tests/check.mjs` даёт 10 из 10. Дополнительно 600 случайных вариантов профиля прогнаны через Python и JS — 0 расхождений. Сверка 10 из 10 также видна в панели «Под капотом».
Отброшено: писать свою логику по README (риск разойтись в мелочах вроде формата чисел в `rule_trace`).

**Тонкости переноса.** Python печатает float `2.0` как «2.0», JS как «2» — сделана функция `pyFloat`. Округление `round(x, 3)` заменено на `toFixed(3)`, проверено на всех профилях. У P6 в ответе нет `path` и `texts`, как в эталоне.

**Один файл без сборщиков и фреймворков.** Данные, движок, код и логотипы встроены в `dist/index.html` (215 КБ). Открывается двойным кликом, публикуется куда угодно.
Отброшено: React и сборка — лишняя точка отказа за сутки до сдачи.

**Публикация через Artifact на claude.ai.** Ссылка готова сразу, обновляется на том же адресе. Запасной вариант: залить `dist/index.html` на GitHub Pages, Netlify Drop или Vercel.
Ограничение площадки: работают только простые якоря, поэтому маршруты `#boss`, `#accountant`, `#manager`, `#tobe`, а не `#/boss?mode=tobe` из ТЗ.

**Все экраны рисуются из одного решения.** Функция `decide()` считает решение движка, `view()` решает, что видно каждому зрителю. Тексты, суммы и даты берутся только из решения и шаблонов `ref_message_templates.csv`.

**AS IS = скоры текущего оптимизатора.** Карусель в ИБ по `ranking_before` (ВЭД 0,482 первым), тексты шаблонов без суммы и даты. У финдиректора предложений нет, калькулятор пустой. У менеджера только «ВЭД 0,48».

**Главная интернет-банка собрана с нуля.** Сохранённой главной «Альфа-Бизнес Онлайн» в архиве не было. Сделана своя главная в стиле Альфы: без адресов, ИНН, счетов, ссылок на сайты банка и кнопки «Выход». Лента операций синтетическая, без контрагентов.

**Записку получает «Сотрудник с правом создания платежей».** Так решает движок: он самый активный в ИБ (17 дней из 30). На экране подпись роли, без ID.

**Карточка J7.** У P1 в прошлой сессии заявка дошла до конца, поэтому на карточке первой стоит «Подать заявку». «Одобрить подачу» осталась, обе ведут в калькулятор, как в ТЗ.

**Калькулятор J1 вживую.** 3 правки суммы или 40 секунд без действий: подсказка «Сумма посчитана по вашим оборотам», сумма возвращается к 48,2 млн, появляется «Обсудить с менеджером». Кнопка «Имитировать паузу» в верхней панели для защиты.

**Подпись условная.** Без полей ключа и пароля, только кнопка «Подписать ЭП». На итоговом экране время от первого показа записки до подписи.

**Бриф менеджеру.** Если его даёт движок, берём текст движка. Если менеджер подключается через холдинг или кнопку «Обсудить», собираем по шаблону T12: «Разрыв 48,2 млн ₽ к 4 декабря, уверенность 0,81. ЛПР — финансовый директор; аргумент: сумма, срок и разрыв».

**Скрытые поля вырезаны.** `role_true_hidden` и `pattern_true` удалены из данных при сборке. ID пользователей на экранах не показываются, каналы выводятся без `(FS_…)`.

**Оформление.** Клиентские экраны в языке Альфа-Банка: белый, красный `#EF3124` только на главном действии. Обвязка в цветах Альфа-Будущего: серый `#EBEBEB`, лайм, фиолетовый, красный, логотип из PDF кейса. Шрифт Onest (Styrene A недоступен). Без «·», без цветных полосок у карточек.

## Расхождения ТЗ с эталонным движком (на P1)

Везде показываем то, что считает движок: совпадение с эталоном обязательно.

| Переключатель | ТЗ ждёт | Движок даёт |
|---|---|---|
| Недель до разрыва > 6 | T04 «Подготовьтесь к сезону» | ВЭД выигрывает (0,482 против 0,402), карточка ВЭД |
| Без сезонности | отраслевой продукт и фраза | ВЭД, отраслевого продукта нет |
| Деньги группы ≥ 48,2 млн | кэш-пулинг, подключается менеджер | кэш-пулинг через карточку, текста для бухгалтера и менеджера нет; записку не показываем, карточку берём из T06 |
| «ФД через менеджера» | бриф менеджеру | у ФД в P1 уже этот тип, решает только «Альфа-Босс»; переключатели объединены |
| Роль ФД в CRM пустая | изменения на экранах | на клиентских экранах ничего, меняется источник роли в панели |
| Нет согласий на рекламу | канал пропадает | в P1 ничего: записка и карточка внутри приложений согласия не требуют; видно в связке с холдингом или «ФД без Альфа-Босса» (звонок становится сервисным) |
| Стройка | «перед сезоном стройки» | у `construction` фраза «до старта строительного сезона», у `construction_trade` «перед сезоном стройки» |

**Для защиты** подойдут «что если», которые ярко меняют экраны: «Растениеводство, АПК» (льготный кредит, фраза «до начала посевной») и «ФД в Альфа-Боссе: нет» (бриф менеджеру с кнопкой «Позвонить»).
